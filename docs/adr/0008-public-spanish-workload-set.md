# ADR 0008 — Public Spanish Workload Set, calibrated against published WER

Status: accepted

## Context

The project had no Spanish **Workload Set**. The only Spanish figures it ever
produced were scored against a **Reference STM** that was itself generated by the
system under test, which makes every derived metric circular and meaningless.

Any replacement must satisfy three constraints:

- **Licensing.** Only freely-licensed public audio may be used, referenced or
  described. No private or domain-specific material.
- **Reproducibility.** A clean checkout must be able to fetch the same items in
  the same order without a manual data request.
- **Falsifiability.** A Spanish number is only worth having if a systematic
  harness error would be visible in it.

Common Voice, the previously wired Spanish option, moved off its previous free
distribution channel in late 2025 and is no longer reproducibly fetchable.

## Decision

### Corpora

| Corpus | Config / split | Licence | Role |
|---|---|---|---|
| VoxPopuli (`facebook/voxpopuli`) | `es` / `test` | CC0-1.0 | primary |
| FLEURS (`google/fleurs`) | `es_419` / `test` | CC-BY-4.0 | calibration |
| Multilingual LibriSpeech (`facebook/multilingual_librispeech`) | `spanish` / `test` | CC-BY-4.0 | calibration |

VoxPopuli is the primary set: CC0, already at 16 kHz, spontaneous parliamentary
speech rather than read prompts, and it ships both a raw and a normalized
transcript field, which maps onto the two metric lanes. FLEURS and MLS are
calibration sets, chosen because published WER exists for the ASR models this
project ships.

The **Reference STM** carries the *raw* transcript. The harness derives its own
normalized lane, so importing a corpus's pre-normalized text would silently mix
two normalization protocols.

### Fetching

Corpora are read from the Hugging Face Parquet index over HTTP `Range` requests,
one row group at a time, stopping as soon as the preset's item count is met.
This keeps the fetch reproducible (same index, same order) without downloading a
multi-gigabyte split to score fifty items. Licence, source dataset and per-item
provenance are recorded in `corpora.json` and `LICENCES.md` beside the clips.

### Calibration

The aggregate normalized ORC-WER of each calibration corpus is compared against
a registered published figure for the configured **ASR Model Selection**. A
deviation beyond a two-sided absolute margin fails the run.

ORC-WER is used because it is diarization-invariant, and these corpora are
single-speaker; cpWER would additionally penalise any speaker split the diarizer
invents, which is not what the check is measuring.

Only externally citable figures are registered (Whisper paper Tables 10 and 13;
the NVIDIA parakeet model card). A model with no registered figure reports
`unregistered` and does not fail the run.

### Quarantine

Reference material under a `benchmark/groundtruth/` tree, or named like a
**Hypothesis STM** (`*.hyp.stm`), is rejected before scoring.

## Consequences

- Spanish validates **ASR quality only**. All three corpora are single-speaker,
  so DER is not meaningful; diarization decisions remain AMI-driven. This is an
  accepted program limitation, not an oversight.
- The Common Voice clip utility is removed rather than left as a dead end.
- Every previously recorded Spanish figure is void and must be re-measured.
- The calibration margin starts wide because the normalized lane currently only
  strips punctuation; it tightens once a diacritic-preserving basic normalizer
  lands.

## Alternatives considered

- **Albayzín-RTVE2020.** The strongest Spanish target — human-revised
  transcripts *and* speaker labels, so it would give trustworthy Spanish DER —
  but it is gated behind an RTVE licence and cannot be redistributed, so it
  cannot back a reproducible workload set.
- **Hand-correcting public Spanish audio into a multi-speaker reference.** Would
  yield Spanish DER, but costs hours of human transcription per run of the
  program and produces an artifact no external figure can calibrate.
- **Keeping Common Voice.** Rejected: no longer freely fetchable, so it fails the
  reproducibility constraint.
